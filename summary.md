# OneTwoBoard — Доска объявлений

Сводка текущего состояния проекта на 04.05.2026

## Общая информация

- **Название проекта:** OneTwoBoard

## Основные модули и их возможности

### Пользователи (users)

- Регистрация с выбором типа: **Частное лицо** или **Компания**
- Вход / выход
- Личный кабинет:
  - Настройки профиля (email, телефон, город, аватар, тип профиля)
  - Управление своими объявлениями (список, редактирование, удаление)
- Все формы оформлены с использованием Bootstrap

### Объявления (listings)

- Создание объявления с **динамической подгрузкой параметров** выбранной категории через AJAX
- Редактирование объявления с сохранением всех полей и параметров
- Удаление объявления с подтверждением
- **Модерация:** новое объявление получает статус «На модерации», видно только автору и администратору; после одобрения становится «Активно»
- Обязательное заполнение всех параметров категории перед публикацией
- Загрузка нескольких изображений, выбор главного
- Детальная страница объявления:
  - Хлебные крошки
  - Галерея с модальным слайдером (листание стрелками и клавиатурой)
  - Цена (отображается над карточкой продавца)
  - Описание, категория, дата публикации
  - Блок контактов с аватаркой автора и кнопкой «Показать телефон» (телефон скрыт до клика)
  - Отображение типа профиля (частное лицо/компания)
- Пагинация (24 карточки на главной, 20 в категориях и поиске)

### Категории (categories)

- Иерархическое дерево (родительские и дочерние категории через ForeignKey)
- **Дерево выбора** при создании/редактировании объявления:
  - Аккордеон: открытие одной ветки закрывает остальные
  - Нельзя выбрать родительскую категорию, только конечную
- Левая боковая панель с деревом категорий на главной странице и страницах категорий
- **Параметры категорий** (CategoryParameter):
  - Типы: choice (выбор из списка), boolean (да/нет)
  - Варианты вводятся через запятую или перевод строки
  - **Наследование параметров:** дочерняя категория автоматически получает параметры всех родительских; можно переопределить
- **Фильтрация по параметрам** на странице категории (через JSONField `parameters` в объявлениях)
- При выборе родительской категории отображаются объявления из неё и всех дочерних подкатегорий
- Админка: управление параметрами встроено в форму категории (inline)

### Поиск (search)

- Полнотекстовый поиск по заголовку и описанию (icontains)
- Фильтр по цене (от/до)
- Сортировка: сначала новые, старые, дешёвые, дорогие
- Пагинация с сохранением параметров фильтра и сортировки
- Блок фильтра и сортировки в виде раскрывающихся панелей (dropdowns)

### Админка

- Кастомные заголовки и стили
- Управление всеми моделями (категории, параметры, объявления, изображения, профили)
- Массовые действия над объявлениями: одобрить, деактивировать, отправить на модерацию
- Предпросмотр аватаров и изображений

## Реализованные ключевые функции

✅ Полный цикл: регистрация → подача объявления → модерация → публикация  
✅ Динамические параметры категорий с наследованием и обязательной валидацией  
✅ Интерактивное дерево категорий (аккордеон, запрет выбора родительских)  
✅ Слайдер изображений в модальном окне с поддержкой клавиатуры  
✅ Скрытый номер телефона, показываемый по клику  
✅ Фильтрация и сортировка в категориях и поиске  
✅ Отображение объявлений из всех подкатегорий при выборе родительской  
✅ Чистая модульная архитектура

## Инструкция по запуску

```bash
cd OneTwoBoard
python3 -m venv venv
source venv/bin/activate      # для Windows: venv\Scripts\activate
pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py createsuperuser
python3 manage.py runserver

Сервер будет доступен по адресу: http://127.0.0.1:8000
Админ-панель: http://127.0.0.1:8000/admin/
