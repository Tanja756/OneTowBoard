# OneTwoBoard — Доска объявлений на Django

Современная доска объявлений с модерацией, иерархическими категориями, динамическими параметрами и отзывчивым интерфейсом.

## Стек технологий

- **Python 3.14**
- **Django 5.2 (LTS)**
- **SQLite** (на старте; легко заменить на PostgreSQL)
- **Bootstrap 5.3** (CDN)
- **Pillow** (обработка изображений)

## Основные возможности

### Пользователи
- Регистрация с выбором типа аккаунта: **Частное лицо** / **Компания**
- Личный кабинет: настройки профиля, аватар, контакты
- Раздел «Мои объявления» с управлением списком

### Объявления
- Подача с загрузкой нескольких фото (главное изображение выбирается автоматически)
- Модерация: по умолчанию объявление попадает на проверку, видно только автору и администратору; после одобрения становится доступно всем
- Динамические параметры, зависящие от выбранной категории (через AJAX)
- Обязательное заполнение параметров категории перед публикацией
- Детальная страница: галерея с модальным слайдером (листание мышью и клавиатурой), цена, контакты (телефон скрыт до нажатия «Показать телефон»)
- Редактирование и удаление автором или администратором

### Категории и параметры
- Иерархическое дерево категорий (вложенность через родительскую связь)
- Интерактивное дерево выбора при создании/редактировании (аккордеон, нельзя выбрать родительскую категорию)
- Кастомные параметры для каждой категории (тип: выбор из списка или да/нет)
- Наследование параметров от родительских категорий (дочерняя получает все параметры предков)
- Фильтрация объявлений по параметрам на странице категории
- При выборе родительской категории отображаются объявления из неё и всех подкатегорий

### Поиск и фильтры
- Полнотекстовый поиск по заголовку и описанию
- Фильтр по цене (от/до)
- Сортировка: по дате (новые/старые) и по цене (дешёвые/дорогие)
- Компактные выпадающие панели для фильтров (в стиле dns-shop)

### Интерфейс
- Полностью адаптивный дизайн на Bootstrap 5
- Карточки объявлений на главной, в категориях и результатах поиска
- Хлебные крошки на детальной странице
- Модальное окно для просмотра фото с возможностью переключения

### Административная панель
- Управление категориями, параметрами, объявлениями, пользователями
- Массовые действия: одобрить, деактивировать, отправить на модерацию
- Предпросмотр изображений и аватаров

## Быстрый старт (локально)

```bash
git clone https://github.com/yourusername/OneTwoBoard.git
cd OneTwoBoard
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py createsuperuser
python3 manage.py runserver

Откройте в браузере:
    Основной сайт: http://127.0.0.1:8000
    Панель администратора: http://127.0.0.1:8000/admin/
